# Flappy Tesla

A browser mini-game inspired by Flappy Bird: pilot a white Tesla Roadster through a neon cyberpunk city. Built with TypeScript, Vite, Tailwind CSS, and the HTML Canvas API.

## Play locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

Static output is written to `dist/`.

## Controls

| Input | Action |
| --- | --- |
| Space, click, or tap | Thrust / start / restart |
| P or Esc | Pause / resume |

Mute and pause are available from the in-game UI.

- [Vite](https://vitejs.dev/)
